# Changelog

## 0.1.0 — pending public release

- Run Biber 2.22 with BCF 3.11 in browser Workers and Node worker threads.
- Verify runtime assets with SHA-256 and prepare verified offline caches.
- Bound queued jobs and support cancellation, timeouts and disposal.
- Compare native Biber goldens, including Unicode and collation data.
- Include component notices, locked build inputs and corresponding sources.

This is the first public release. Remote bibliography downloads, arbitrary Perl
execution and implicit server fallback are outside the supported API.
