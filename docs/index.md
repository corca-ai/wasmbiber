# WasmBiber documentation

WasmBiber runs the real Biber bibliography processor in an isolated WebAssembly
Worker. Start with [integration](integration.md) for browser and Node use, then
consult the [API contract](api.md).

For supported inputs and native comparison rules, read [compatibility](compatibility.md).
[Offline assets](offline.md) explains preparation, integrity and persistence.

Contributors should read [architecture](architecture.md), [development](development.md)
and [testing](testing.md). Runtime maintenance is covered by [build](build.md),
[performance](performance.md) and [distribution](distribution.md).
[Documentation rules](documentation.md) distinguish current contracts from evidence.

[Public releases](releasing.md) owns publication preparation and the maintainer checklist.
